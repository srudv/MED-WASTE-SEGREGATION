# 06 — Dashboard

## Purpose
This folder contains the interactive dashboard deliverable for exploring medical-waste segregation information and presenting selected project metrics and visualizations.

## Files
- `AI-Driven Medical Waste Segregation System ( dashboard ).pbix` — Power BI dashboard project file.

## How to open
1. Install/open Microsoft Power BI Desktop.
2. Download or clone this repository.
3. Open the `.pbix` file in Power BI Desktop.
4. If Power BI asks for a data source location, reconnect it to the appropriate cleaned CSV in `../03_Data_Cleaning/MedWaste_AI_Cleaned_1500_Records.csv` and check that the fields and data types match.
5. Refresh the data and inspect the visuals before presenting or publishing the dashboard.

## Validation checklist
- Confirm that the report uses the current cleaned dataset.
- Check all data-source paths and refresh successfully.
- Verify chart titles, units, filters and category labels.
- Ensure dashboard figures agree with the current analysis outputs.
- Clearly identify the dataset as simulated/unverified if that remains its provenance.

## Limitations
A `.pbix` file is a Power BI Desktop project; it is not by itself a publicly hosted live dashboard. Do not describe the dashboard as deployed or connected to live hospital sensors unless that has been separately implemented and tested.
