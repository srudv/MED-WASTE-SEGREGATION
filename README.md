# MED-WASTE-SEGREGATION
## Project Overview

MED-WASTE-SEGREGATION is a data-focused project intended to organize and analyze available medical-waste information and present findings through visualizations and an interactive dashboard.

## Project Workflow

1. Project proposal and scope definition
2. Data collection and source documentation
3. Data cleaning and preprocessing
4. Exploratory data analytics
5. Data visualization
6. Interactive analytics dashboard

## Project Status

Currently working on project planning, documentation, and dataset preparation.

## Important Notes

- Findings will be based on the dataset actually collected and validated.
- Data sources and licenses must be documented.
- Confidential patient data and credentials must not be committed.
- Installation and execution instructions will be added as the implementation progresses.
