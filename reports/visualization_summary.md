# Visualization Summary — Biomedical Waste Analytics (2023)

## Charts created

Seven charts are generated by `src/visualization.py` and `notebooks/03_data_visualization.ipynb`. Exported PNG and SVG versions are stored in `reports/figures/`.

1. Top 10 biomedical waste generators — daily quantity in kg/day.
2. Generated vs treated/disposed — paired comparison for the ten largest generators.
3. Treatment-route donut — reported captive vs CBWTF quantities.
4. Generation histogram — distribution across reporting entities.
5. Healthcare facilities vs generation — one point per reporting entity.
6. CBWTF infrastructure — operational vs under-construction facility counts.
7. Top 10 recorded violations — reported HCF/CBWTF violation counts.

## Key values

- Total generation: **743,147.531 kg/day**.
- Treated/disposed: **694,353.322 kg/day** (93.43% aggregate ratio; not a verified compliance rate).
- Captive treatment: **22,656.631 kg/day**; CBWTF treatment: **671,696.582 kg/day**.
- CBWTFs: **234 operational**, **30 under construction**.
- Highest generation: **Uttar Pradesh, 99,115.08 kg/day**.
- Highest recorded violations: **Uttar Pradesh, 3,503**.

## Interpretation limitations

The source covers calendar year 2023 only and is aggregated by State/UT. It contains no monthly or multi-year observations, so time-series charts are not appropriate. It also lacks yellow/red/white/blue waste-category quantities, so category distribution charts cannot be produced. The generated-vs-treated comparison is not proof that the difference represents untreated waste. Missing source fields are not interpreted as zero. Correlation does not imply causation.

## Reproduce

```bash
pip install -r requirements.txt
python -m src.visualization
jupyter notebook notebooks/03_data_visualization.ipynb
```

The script exports all seven charts as PNG and SVG. The notebook checks that each export exists and is non-empty. Run locally to verify all cells and rendering in your environment.
